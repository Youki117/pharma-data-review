# 资料核对工具

Windows 本地桌面程序，在同一窗口中切换三个页面：

1. 方法验证：一份 `.docx` 验证报告与对应 `.xlsx` 计算表，检查数据来源及引用差异。
2. 稳定性：汇总表与原始检验报告单逐值对账，按确定性和人工复核优先级分档。
3. 内容一致性：1～10 份相关 `.docx`，检查汇总与正文、上下文及跨文件差异。

支持原生文件／目录拖放和多层目录读取。需求一、三支持按一级目录分批，也可整个目录一批；多文件配对不明确时提示整理，不自动猜配。

v1.4.4 改进稳定性合并项目与范围限定的比较，归一明确的写法差异；内容核对识别段落前的批号，区分不同批次的独立测量。复杂业务口径继续保留待确认项。

## 新手引导

第一次打开自动显示分步引导，高亮任务页面、资料导入、可选 AI、开始核对与结果入口。目标区域保持明亮，周围遮罩压暗；紧凑说明气泡贴近目标，自动选择下方、上方或侧边，随窗口与页面位置更新。可随时跳过，右上角“使用引导”可重新打开；支持上一步、下一步和 Esc 退出。

完成或跳过后，在当前 Windows 用户的 `%LOCALAPPDATA%/pharma-data-review/产品/guide-seen` 记住状态，重启或更新后不重复弹出；三合一、独立方法验证和内容核对分别记录。关闭程序但未完成或跳过时，下次仍会提示。引导不导入资料、不启动核对、不调用 AI；核对或更新期间暂不可打开。

## 下载和更新

从 [Releases](https://github.com/Youki117/pharma-data-review/releases/latest) 下载 `review-suite-v版本.zip`，解压到新目录，双击 `资料核对工具.exe`，保留 `_internal` 文件夹。Windows 需要 Edge WebView2。

每次启动会后台检查本仓库的最新正式 Release。右上角版本按钮可查看状态、更新说明和手动重试；断网仍可正常核对。有新版时确认“更新并重启”，程序先下载校验完整运行包，再由临时助手等待旧进程退出、替换原位置并重启。

只替换主程序、`_internal` 运行环境和使用说明，在原目录 `.review-backup` 内保留一份上一版程序文件。新版未能打开时自动恢复并重新打开旧版；原入口、目录外的结果数据，以及程序目录内其他文件保持原位。备份目录存在额外文件时停止更新，不清理用户资料。下载缓存由新版在助手退出后清理。

原目录必须有写权限。旧 v1.3.0 的更新器仍会按原机制完成第一次升级；希望立即使用固定位置的用户请手动下载本版，后续更新均替换该位置。已有历史版本目录不会被新版擅自删除。

发布以正式 Release 和完整运行包为准；单纯推送源码不会触发桌面更新。独立需求一／三分别使用 `review-method-v版本.zip`、`review-content-v版本.zip`，共用相同发布通道。

## AI 与本地模式

需求一、三无需密钥即可本地筛选，结果明确标为“本地筛选完成”。在“设置”填写兼容接口的密钥后自动启用 AI，默认 DeepSeek；三合一的这两个页面共用当前会话连接设置。可清除密钥切回本地模式。

密钥只留在内存，关闭或升级重启后需重新填写。启用 AI 时，选定资料的文本会发送到所配置接口并使用账户额度。可恢复的输出中断最多自动重试一次，可能产生第二次请求费用；失败保留本地候选及明确提示。稳定性核对使用本地确定性逻辑。

## 结果和限制

结果提供分级提要、原文证据及定位。AI 建议必须核实引用，自由文本推断不自动进入“必看”；零候选不代表完整审核通过。

当前解析 Word 正文与顶层表格、Excel 缓存值；不执行 Excel 重算。图片、扫描内容、部分嵌套表格及公式对象有覆盖限制。稳定性 `.doc` 转换依赖本机 Word／WPS／ONLYOFFICE／LibreOffice 之一。实际模型判断质量及不同业务资料的适配需要单独验收。

核对报告含原文，应按源文件管理。默认输出到 `%LOCALAPPDATA%/资料核对工具/结果/`；公开仓库不含任何业务样本、核对结果、回归基线、密钥或开发仓库历史。源码中的业务案例注释及说明也已移除，运行判据保留。

## 源码运行

开发和打包使用 Python 3.12；便携包已包含运行环境。

```powershell
python -m pip install -r requirements.txt
python 资料核对工具/suite.py
```

目录保持原有模块分工：`本地对账工具/` 为稳定性核心，`方法验证核对/` 提供报告／计算表解析、AI 传输及共用界面，`内容一致性核对/` 提供内容筛选，`资料核对工具/` 提供整合、批次队列和更新。

## 验证和构建

```powershell
python -m unittest discover -s 资料核对工具/tests -v
python 资料核对工具/build.py
python 方法验证核对/build.py
python 内容一致性核对/build.py
```

构建需要 PyInstaller，产物在各目录 `dist/v版本/`。公开测试只覆盖更新机制；业务真语料及其回归测试保留在本地开发环境，不公开。新克隆的仓库可运行程序，无法复现未分发的业务语料测试。

字符相似检查使用 Unicode UTS #39 的数字相关字符映射，配合 Python 的 NFKC 归一处理，参见 [Unicode Security Mechanisms](https://www.unicode.org/reports/tr39/)。
